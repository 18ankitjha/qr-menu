Questions

Do guests need to install an app?

No. The QR opens the menu in the phone’s browser. Guests sign in with Google only when they want to order or call a waiter, so everyone at the table shares one cart and bill.

Can I use it only as a digital menu?

Yes. In Customer Menu settings choose “View only”. Guests browse the menu and can still call a waiter or ask for the bill; your waiters take the order.

How do waiters know which table needs them?

When a guest taps “Call waiter” or “Request bill”, every logged-in waiter hears a ring and sees “Table N called a waiter”. If you have no waiters set up, the owner gets the alert instead.

What if a printed QR is shared or photographed?

Regenerate that table’s QR from the Tables page — the old code stops working straight away.
